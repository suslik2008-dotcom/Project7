Вариант 40. Мониторинг реактора: перепад давления. Определение количества теплоты от давления.

1. Начало
2. Вводим давление x(В бар). Нормальный диапазон: 0.5-2 бар
3. Рассчитываем полученную теплоту с помощью одного из 3 формул в зависимости от значения x  
   Если х < 0.5: q = pow(x-0.5, 2) + 8  
   Если 0.5 <= x <= 2: q = 2 * pow(x+0.75, 0.5) + 42  
   Если x > 2: q = 3*x + 54  
4. Выводим полученное значение теплоты q

Расчёты:  
для x = 0.3: q = pow(0.3-0.5, 2) + 8 = 0.04 + 8 = 8.04
для x = 0.69: q = 2 * pow(x+0.75, 0.5) + 42 = 2 * pow(1.44, 0.5) + 42 = 2 * 1.2 + 42 = 44.4
для x = 3: q = 3*x + 54 = 9 + 54 = 63
